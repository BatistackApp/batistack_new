# Réalité Augmentée (AR)

Batistack permet d'utiliser la Réalité Augmentée pour visualiser les maquettes IFC (BIM) directement sur le terrain, superposées à l'environnement réel. Cette fonctionnalité est particulièrement utile pour comparer la maquette avec la réalisation, ou pour visualiser les réseaux (plomberie, électricité, gaines de ventilation) à travers les murs et plafonds avant travaux.

## Prérequis

- **Appareil compatible** : Un smartphone ou une tablette récente supportant l'API WebXR (ex: Android avec Google Chrome). Sur iOS, le support natif dépend de la version de Safari ou nécessite des navigateurs tiers compatibles XR.
- **Fichier IFC** : La fonctionnalité est actuellement disponible uniquement pour les formats de maquette BIM (IFC).

## Comment utiliser le Mode AR

1. Ouvrez le module **Vision 3D** depuis l'application Batistack sur votre appareil mobile.
2. Ouvrez une **Maquette 3D** (format IFC).
3. Si votre appareil est compatible, un bouton **"Mode AR"** apparaîtra en bas à gauche du visualiseur 3D.
4. Appuyez sur **Mode AR**. Le navigateur vous demandera l'autorisation d'accéder à la caméra.
5. Déplacez lentement votre appareil pour qu'il reconnaisse le sol et l'environnement spatial.
6. Un **réticule blanc (cercle)** apparaîtra sur les surfaces détectées. Visez l'endroit où vous souhaitez "poser" la maquette (par exemple, le sol de la pièce) et appuyez sur l'écran.
7. La maquette 3D s'affichera à l'échelle 1:1 à cet emplacement. 
8. Vous pouvez alors vous déplacer physiquement pour inspecter la maquette sous tous les angles.

> **Astuce :** Utilisez le menu "Calques" avant de lancer l'AR pour masquer certains éléments (ex: masquer les murs et planchers) afin de ne visualiser que les tuyauteries ou la structure interne en réalité augmentée !

## Quitter le mode AR

Pour terminer la session, appuyez sur le bouton rouge **"Quitter AR"** (ou utilisez la navigation retour de votre appareil). Vous reviendrez à la vue 3D classique.
