# 🧊 Module Vision 3D (BIM)

Bienvenue dans la documentation du module **Vision 3D**. 

Batistack n'est pas seulement un ERP de gestion financière ou RH ; il intègre une véritable visionneuse de maquettes 3D et de plans techniques pour faire le pont entre le bureau d'études et les équipes sur le terrain.

Ce module vous permet d'importer vos plans et maquettes, de les visualiser directement dans votre navigateur, et d'y ajouter des annotations intelligentes reliées à la vie du chantier.

## 📑 Sommaire du module

Découvrez comment tirer le meilleur parti de vos fichiers 3D :

- [Gestion des Maquettes 3D](./01-maquettes-3d.md) : Formats supportés, importation et visualisation.
- [Annotations et Liaisons métier](./02-annotations-et-liaisons.md) : Comment placer un point d'intérêt sur la maquette et le lier à une tâche de chantier ou une intervention.
- [Réalité Augmentée (AR)](./03-realite-augmentee.md) : Superposer la maquette sur le terrain avec un smartphone ou une tablette.

> [!TIP]
> **Pourquoi utiliser la Vision 3D ?**
> La maquette 3D n'est plus réservée aux architectes. En liant un problème de chantier (ex: fuite détectée) directement aux coordonnées 3D exactes du tuyau sur la maquette, vos équipes de maintenance savent exactement où intervenir avant même d'arriver sur place.
