# 📤 Exports comptables

Ce volet vous permet de produire, en quelques clics, les fichiers que transmet votre expert-comptable.

## 1. Accéder à l'export

Dans le panel **Banque**, ouvrez **Comptabilité → Export Comptable**. Vous choisissez :

- l'**exercice** (année) à exporter,
- le **format** de sortie.

Deux boutons sont disponibles : **« Aperçu »** pour visualiser les écritures avant export, et **« Générer l'export »** pour télécharger le fichier.

## 2. Les formats disponibles

| Format | Usage |
|--------|-------|
| **FEC** | Fichier des Écritures Comptables — le format légal français standard, à joindre à toute demande de l'administration. |
| **Sage 50** | Import direct dans Sage 50 (CSV, séparateur `;`). |
| **Cegid Flow** | Import direct dans Cegid Flow (CSV, séparateur `;`). |

> [!NOTE]
> **Aperçu avant envoi**
> Utilisez toujours l'**Aperçu** pour contrôler les écritures et la **balance générale** (totaux débit/crédit et soldes par compte) avant de générer le fichier définitif.

## 3. Bonnes pratiques

- **Lettez vos transactions bancaires** avant d'exporter : les écritures proviennent du lettrage (voir [Plan comptable & écritures](./01-plan-comptable-et-ecritures.md)).
- Choisissez un exercice **clos** pour un export fiable destiné à la liasse.
- Conservez une copie horodatée de chaque export pour votre archive.

> [!TIP]
> **Une question sur un format ?**
> Le FEC est universel (exigible par l'administration) ; Sage 50 et Cegid Flow dépendent du logiciel de votre expert-comptable. Confirmez avec lui le format attendu.
