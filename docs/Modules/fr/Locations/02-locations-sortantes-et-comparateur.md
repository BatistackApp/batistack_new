# 📤 Locations Sortantes & Comparateur

Batistack ne se contente pas de suivre vos dépenses, il vous aide aussi à acheter au meilleur prix et à rentabiliser vos propres équipements.

## 1. Le Comparateur de Prix Fournisseurs

Avant même de signer un contrat de location entrante, utilisez le **Comparateur de Prix**.
- Renseignez votre besoin (ex: location d'une mini-pelle pour 45 jours).
- Le système consulte la base de données de toutes les grilles tarifaires de vos fournisseurs (Tarifs journaliers, hebdomadaires, mensuels).
- Il calcule de manière algorithmique le meilleur "mix" (ex: 1 mois + 2 semaines + 1 jour) et vous suggère le fournisseur le plus économique pour cette durée précise.

## 2. Locations Sortantes (Rentabiliser votre matériel)

Vous possédez du matériel (enregistré dans le module *Immobilisations*) qui dort dans l'entrepôt ? Louez-le !

Le module permet de générer des **Contrats de Location Sortante** :
1. Vous sélectionnez un client et le matériel interne que vous souhaitez lui louer.
2. Le statut de votre machine passe automatiquement en **"LOUÉ"** (impossible de l'assigner à un de vos propres chantiers).
3. Le système génère automatiquement les Factures Clients récurrentes selon l'échéancier défini.
4. Au retour, le statut de la machine repasse en "DISPONIBLE".
