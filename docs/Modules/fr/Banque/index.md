# 🏦 Module Banque & Trésorerie

Bienvenue dans la documentation du module **Banque** de Batistack.

Ce module est le centre de contrôle financier de votre entreprise. Il ne s'agit pas seulement de consulter le solde de vos comptes, mais de connecter directement votre réalité bancaire à votre gestion commerciale (achats, ventes, paie).

Grâce à des fonctionnalités d'Open Banking et d'intelligence artificielle, l'ERP automatise le rapprochement entre ce que vous facturez et ce que vous encaissez réellement.

## 📑 Que trouverez-vous dans ce module ?

Le module s'articule autour de trois grands piliers :

- [La Synchronisation Bancaire](./01-synchronisation-bancaire.md) : Connectez vos banques via Open Banking ou importez vos relevés.
- [Le Rapprochement Bancaire (Lettrage)](./02-rapprochement-bancaire.md) : Découvrez comment l'ERP associe automatiquement un paiement à une facture.
- [La Trésorerie et les Prévisions](./03-tresorerie-et-previsions.md) : Suivez votre *Cash Flow* et utilisez les outils de clôture mensuelle pour votre expert-comptable.

> [!TIP]
> **Finie la saisie double !**
> L'objectif principal de ce module est de vous faire gagner du temps. Lorsqu'un client paie une facture, la transaction remonte automatiquement dans l'ERP, et la facture passe en statut "Payée" sans aucune action de votre part !
