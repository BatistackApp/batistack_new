# 📲 L'Espace Conducteur de Travaux

Le **portail Terrain** regroupe, dans une interface mobile pensée pour le chantier, toutes les opérations quotidiennes du conducteur de travaux. Il complète les fonctions de bureau du module [Chantiers](./index.md).

## 1. Suivre ses chantiers

- **Mes Chantiers** : accès rapide à ses chantiers actifs et à leur détail.
- **Journal de Chantier** : consigner l'activité du jour (météo, présents, avancement). Voir [Le Journal de Chantier](./02-journal-de-chantier.md).
- **Maquettes 3D / Plans** : consulter les maquettes BIM et les plans directement sur site.

## 2. Gérer les équipes et le matériel

- **Pointage Équipe** : saisir les heures de son équipe (saisie collective) puis **valider les pointages**.
- **Scan Matériel** : scanner le QR code d'un engin pour tracer son entrée / sortie de chantier.
- **État des Lieux** : réaliser l'état des lieux du matériel loué (photos, protections en cas de litige).

## 3. Qualité et réserves

- **Checklists** : exécuter les contrôles qualité planifiés. Voir [Qualité & Sécurité](./04-qualite-et-securite.md).
- **Réserves / OPR** : signaler une réserve sur le terrain, suivre sa prise en charge et sa levée. Voir [Levée des Réserves & OPR](./05-levee-des-reserves-opr.md).

## 4. Documents

- **Documents** : consulter les documents de chantier (plans, DOE partiels, comptes-rendus).

> [!TIP]
> **Conçu pour le terrain**
> Interface tactile, boutons larges et fonctions utilisables sur mobile : l'espace conducteur réduit la ressaisie entre le chantier et le bureau, et fiabilise les remontées d'information.
