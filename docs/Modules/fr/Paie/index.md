# 💶 Module Paie

Bienvenue dans la documentation du module **Paie** de Batistack.

La paie est l'aboutissement de tout le travail saisi dans l'ERP (les contrats du module RH, les pointages du module GPAO, les absences). Ce module centralise le calcul des bulletins de salaire, la gestion des acomptes, et la génération des exports obligatoires.

## 📑 Que trouverez-vous dans ce module ?

Le module Paie est conçu pour simplifier la vie de votre service RH et de votre comptable :

- [Bulletins & Calculs Automatisés](./01-bulletins-et-calculs.md) : Découvrez comment le moteur de paie récupère les heures travaillées pour calculer automatiquement le Brut, le Net et les cotisations.
- [Exports & Comptabilité](./02-exports-et-comptabilite.md) : Générez en un clic vos virements SEPA, vos exports sociaux (DSN) et l'OD comptable (Journal de Paie).
- [Espace Salarié & Acomptes](./03-espace-salarie-et-acomptes.md) : Pilotez les demandes d'avances et permettez à vos employés de télécharger leurs fiches de paie depuis un portail sécurisé.

> [!NOTE]
> **Profils de Cotisations (BTP)**
> Le moteur de paie de Batistack intègre déjà des profils de cotisations avancés (comme le profil Bâtiment ETAM) incluant les réintégrations fiscales spécifiques (mutuelle, OPP BTP, congés). Il évolue avec la législation.
