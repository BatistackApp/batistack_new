# ⚙️ Module Core (Fondations)

Bienvenue dans la documentation du module **Core** de Batistack.

Ce module est invisible pour la plupart des employés de terrain, mais il constitue la colonne vertébrale technique de l'ERP. C'est ici que sont hébergés tous les paramètres fondamentaux et les moteurs qui font fonctionner les autres modules (Ventes, Chantiers, RH).

## 📑 Que trouverez-vous dans ce module ?

En tant qu'Administrateur, c'est ici que vous configurerez le comportement global de votre logiciel :

- [Configuration & Entreprise](./01-configuration-et-entreprise.md) : Gestion de votre entité juridique (SIREN), des taux de TVA, et des unités de mesure.
- [Sécurité & Droits d'Accès](./02-securite-et-droits.md) : Gestion fine des permissions, synchronisation avec les contrats RH, et piste d'audit (qui a fait quoi ?).
- [Services Transverses (Moteurs)](./03-services-transverses.md) : Explication des services partagés comme la génération de PDF, la signature numérique, la géolocalisation et la météo.

> [!TIP]
> **Le centre névralgique**
> Une modification effectuée dans les paramètres de TVA du module Core impactera immédiatement tous les futurs Devis et Factures du module Commerce. Soyez prudent lorsque vous manipulez ces réglages !
