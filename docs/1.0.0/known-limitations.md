# Limitations connues 1.0.0

Les éléments suivants ne doivent pas être présentés comme inclus dans le périmètre garanti de la 1.0.0 :

- télétransmission DSN M2M URSSAF/Net-Entreprises ;
- collecte avancée des documents légaux via tous les connecteurs externes ;
- OCR avancé et validation de documents sans configuration Google Vision ;
- signature AES / eIDAS avancée, PAdES et horodatage qualifié ;
- connexion IoT / OPC-UA des machines ;
- télématique OBD ou GPS avancée ;
- extraction automatique des quantitatifs IFC.

Les intégrations externes nécessitent leurs propres credentials, quotas, contrats et tests de disponibilité. Les tests automatisés avec mocks ne constituent pas une validation de production du fournisseur externe.
